# WEEK 8 - Git Hands-on Lab

## 📌 Introduction

This repository contains practical exercises from **Week 8 Git Hands-on Labs** (Git_HOL1 to Git_HOL5).  
Each hands-on activity includes terminal commands, code snippets, and screenshots documented in `.docx` files.

The labs focus on developing a strong understanding of Git workflows including configuration, branching, merging, conflict resolution, and pushing code to a remote repository.

---

## 🎯 Objectives

- Familiarize with Git commands such as `git init`, `git status`, `git add`, `git commit`, `git push`, and `git pull`.
- Configure Git on your local machine.
- Integrate Notepad++ as the default Git editor.
- Add and ignore files in a Git repository.
- Use branching and merging.
- Resolve merge conflicts.
- Push code to a remote GitHub repository.

---

## 🛠 Prerequisites

- Git Bash client installed.
- Notepad++ installed (optional, for editor config).
- A GitHub account.  
  ⚠️ **Do not use Cognizant credentials.**

🕒 **Estimated Time**: ~2 hours total for all exercises

## 🧪 Hands-on Exercises Summary

### ✅ Git_HOL1 – Git Setup & Configuration

**What I Learned:**
- Configured Git user details (`user.name`, `user.email`)
- Verified Git installation using `git --version`
- Set Notepad++ as the default editor for Git
- Initialized a Git repository

**🗎 Attached Output:** `Git_HOL1_Output.docx`

---

### ✅ Git_HOL2 – Git Ignore

**What I Learned:**
- Created `.gitignore` file
- Ignored specific file types like `.log` and folders like `log/`
- Verified exclusions using `git status`

**🗎 Attached Output:** `Git_HOL2_Output.docx`

---

### ✅ Git_HOL3 – Branching and Merging

**What I Learned:**
- Created new branch `GitNewBranch`
- Switched branches and made changes
- Used `git merge` to merge changes into master
- Visualized changes using P4Merge and `git log --oneline --graph --decorate`

**🗎 Attached Output:** `Git_HOL3_Output.docx`

---

### ✅ Git_HOL4 – Conflict Resolution

**What I Learned:**
- Created conflicting changes between `master` and `GitWork` branch
- Merged branches and resolved conflicts using a 3-way merge tool
- Used `.gitignore` to exclude backup files
- Cleaned up by deleting merged branches

**🗎 Attached Output:** `Git_HOL4_Output.docx`

---

### ✅ Git_HOL5 – Clean Up and Push to Remote

**What I Learned:**
- Verified clean state using `git status`
- Pulled latest changes using `git pull origin master`
- Pushed local commits using `git push origin master`
- Confirmed updates on GitHub

**🗎 Attached Output:** `Git_HOL5_Output.docx`
