## 📝 Hands-On Exercises Summary

### 🔹 9_REACT_HOL - **cricketapp**
- **Topic:** ES6 features in React
- **Learned:** `map()`, arrow functions, destructuring, props, and reusable components.

### 🔹 10_REACT_HOL - **officespacerentalapp**
- **Topic:** JSX and styling
- **Learned:** JSX syntax, inline CSS, JavaScript expressions in JSX, and conditional styling.

### 🔹 11_REACT_HOL - **eventexamplesapp**
- **Topic:** Event handling in React
- **Learned:** Handling synthetic events, using `this` keyword, and writing event handlers.

### 🔹 12_REACT_HOL - **ticketbookingapp**
- **Topic:** Conditional rendering
- **Learned:** Switching views for guest and logged-in users using ternary and logical operators.

### 🔹 13_REACT_HOL - **bloggerapp**
- **Topic:** Lists and keys
- **Learned:** Rendering multiple components using `map()`, assigning unique keys, and extracting reusable components.
